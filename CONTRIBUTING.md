# Contributing

For a rule contribution, state the exact linguistic claim, rule ID and version, recognition boundary, positive examples, negative near matches, Unicode/span tests, known limitations, and provenance for every fixture. Use newly written synthetic examples; any public-reference material needs separately verified redistribution rights. Do not submit private learner sentences, screenshots, logs, or account data. A maintainer must review both linguistic claims and code before merging. Bug reports should provide a minimal synthetic reproduction and expected rule behavior.
